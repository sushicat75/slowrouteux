# slowroute

A UI/UX focused redesign of [slowroute](https://mrt-map.github.io/slowroute), a navigator for the [Minecart Rapid Transit server](https://minecartrapidtransit.net) powered by TypeScript. Data comes from [gatelogue](https://github.com/mrt-map/gatelogue). Thanks to Kev Quirk for [simple.css](simplecss.org).

If you notice any bugs, please use the issues tab. Report it under "Backend", "Frontend", or "Unknown". The backend is unchanged from the original project, so if there is a backend error the devs of the original project. If routing data is not up to date, please see [gatelogue](https://github.com/mrt-map/gatelogue).
