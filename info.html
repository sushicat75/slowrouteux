slowroute ux-info

information about the project, where the data comes from, and why its might be so slow.

General info Slowroute ux is a redesign of the routing service slowroute.
What is it for? It's for the Minecart Rapid Transit server, a minecraft server with a lot of transit.
Open source! This project is open source under the GPL 3.0! That means you can contribute to it and fork it as long as you keep the same license.
where is the data from/why is it not up to date The data for the routing service is from gatelogue, a database of transit services. You can go there to help update it.
source code/contributing/bug report The source code is on GitHub here.
why is it taking forever to load? It all has to run on your device and there are a lot of stations and routes so it tries to find the best one.
